照片局部模糊工具

使用方式：
1. 開啟 index.html。
2. 選擇照片。
3. 用「模糊筆」塗抹要模糊的位置。
4. 可調整筆刷大小、模糊程度、柔邊程度；調整後只影響接下來畫的新筆畫。
5. 可用「橡皮擦」移除已塗抹區域。
6. 選擇 PNG 無損或 JPG 高品質後下載；支援的瀏覽器會跳出另存新檔視窗，可選位置與改檔名。
7. 在圖片上按住 Ctrl 並滾動滑鼠滾輪，可以用滑鼠位置為中心放大或縮小編輯視圖。

畫質說明：
- 編輯畫面可能會縮小顯示，但內部畫布維持照片原始解析度。
- Ctrl + 滾輪只改變編輯時的顯示倍率，不會改變下載圖片的解析度或畫質。
- 下載時會用原始寬高輸出。
- PNG 是無損格式；JPG 會以高品質輸出，但格式本身仍會有壓縮。
- 如果瀏覽器不支援另存新檔視窗，會退回一般下載。

範圍：
- 模糊程度：0.0 到 10.0 px。
- 筆刷大小：0.0 到 100.0 px。
- 柔邊程度：0.0 到 15.0 px，套用在整段筆畫邊緣，不會放大筆刷範圍。
